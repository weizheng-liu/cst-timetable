# 成績評価の分類ルール

シラバスの「成績評価」は自由記述なので、次の手順で機械的に分類している。
ルールは **`data/config/evaluation_rules.json`** にあり、コードを触らずに調整できる。
変更したらスクレイパーを再実行（Actions の *Update syllabus data* を手動実行）すると全科目に反映される。

## 1. 割合の抜き出し

本文中の `数字 + %（全角・半角）` をすべて探し、その直前（改行・読点・カンマまで）を項目名とする。

```
理解度確認テスト(45％)、中間試験(25％)、宿題(20％)、取り組み(10％)
→ 理解度確認テスト 45 / 中間試験 25 / 宿題 20 / 取り組み 10
```

## 2. 項目名のカテゴリ判定

`categories` を **上から順に** 調べ、`keywords`（正規表現）に最初に一致したカテゴリにする。
`exclude` に一致したらそのカテゴリは飛ばす。

| 順 | id | 表示 | 主なキーワード | 備考 |
|---|---|---|---|---|
| 1 | quiz | 小テスト | 小テスト, ミニテスト, 確認テスト | 「理解度確認」は除外（＝試験扱い） |
| 2 | exam | 試験 | 試験, テスト, 期末, 中間, 定期, 考査 | 理解度確認テストはここ |
| 3 | report | レポート・課題 | レポート, 課題, 宿題, 提出物, 演習問題, 作品, 製図, 製作, 週報 | |
| 4 | attendance | 出席・平常点 | 出席, 参加, 取り組み, 授業態度, 平常, リアクション, 実施度 | 「授業参加度・発表」は参加が先に当たり出席扱い |
| 5 | presentation | 発表 | 発表, プレゼン, 口頭, ディスカッション | |
| — | other | その他 | どれにも当たらない | |

## 3. タグ（絞り込みに使う）

カテゴリごとの合計（%）で判定する。

| タグ | 条件 |
|---|---|
| 試験なし | 割合が 1 つ以上読み取れ、かつ「試験」カテゴリの合計が 0%（小テストは含まない） |
| レポート中心 | 「レポート・課題」が 50% 以上 |
| 出席重視 | 「出席・平常点」が 30% 以上 |
| 試験重視 | 「試験」が 60% 以上 |

## 限界

- 割合が書かれていない科目（「総合的に評価する」など）はタグが付かない。詳細カードには原文をそのまま表示する。
- 前期・後期で評価が分かれている年間科目は、両方の割合を合算している（合計が 100% を超えることがある）。
- 判定はあくまで目安。最終的には詳細カードのシラバス原文を確認すること。
